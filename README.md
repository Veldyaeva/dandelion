# Dandelion

Персональное Obsidian-хранилище для заметок, целей, проектов, ежедневных записей и справочных материалов.

## Как открыть

1. Откройте Obsidian.
2. Выберите `Open folder as vault`.
3. Укажите папку `C:\Users\soft-otdel\Documents\Zmiy\dandelion`.
4. Начните с заметки [[Главная]].

## Структура

- `00 Inbox` - быстрые входящие заметки, идеи и черновики.
- `01 Daily` - ежедневные записи.
- `02 Areas` - долгосрочные сферы жизни.
- `03 Projects` - активные персональные проекты и цели.
- `04 Resources` - справочные материалы, списки и знания.
- `05 Archive` - завершенное и больше не актуальное.
- `Templates` - шаблоны для новых заметок.

## Рабочий ритм

- Новые мысли сначала фиксируются в `00 Inbox`.
- В конце дня входящие заметки распределяются по проектам, сферам или архиву.
- Ежедневная заметка связывает задачи, события и мысли за конкретную дату.
- Проекты имеют ожидаемый результат, следующие действия и дату пересмотра.
